# WitcherSigns — Minecraft Forge 1.7.10

Source project for a lightweight Witcher-inspired Signs mod.

## Status and build
This archive contains source code and a ForgeGradle 1.2 build definition. It is **not** a compiled mod JAR. The execution environment used to prepare this project had Java 21 but no Java 7/8 toolchain, no Gradle installation, and no network/DNS access to retrieve ForgeGradle and Minecraft dependencies. Consequently, I could not honestly compile or launch-test a working JAR here.

To produce a JAR, the project must be built in an environment with a compatible Java 8 setup and access to the ForgeGradle/Minecraft 1.7.10 artifacts. The intended output is `build/libs/WitcherSigns-1.0.0.jar`.
